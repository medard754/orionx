Votre agent, chez vous.

L'espace client en ligne arrive avec les abonnements. En attendant, le tableau de bord d'ORIONX s'ouvre directement sur votre ordinateur : vos données et vos ordres ne quittent jamais votre machine.

Être prévenu de l'ouverture Retour à l'accueil

Ouvrir le tableau de bord local

Depuis le dossier de l'agent, lancez :

python -m orionx.main run --api --dashboard

Le navigateur s'ouvre automatiquement, sans mot de passe à saisir : la connexion se fait par un code à usage unique, sur votre machine uniquement.

Pourquoi pas de connexion ici ?

Nous ne demanderons jamais vos identifiants tant que l'espace client sécurisé n'est pas prêt. Méfiez-vous de toute page qui vous demanderait vos accès ORIONX ou ceux de votre courtier.
